# Vision as a Service

A Streamlit application that runs YOLO detection on uploaded images.

## Source

- [App_code/app.py](App_code/app.py)
- [Deploying a Vision-as-a-Service Web App.py](Deploying%20a%20Vision-as-a-Service%20Web%20App.py)

## How to explore

Run `python -m pip install -r App_code/requirements.txt` and `python -m streamlit run App_code/app.py`. Upload an image to inspect the detector’s output.
